# 闸门与记录系统

> 闸门的价值不在"问一句"，而在**每次都有固定形状的工件**。没有工件，闸门会退化成"我觉得可以了"。

## 闸门 A · 方案冻结

工件 = `templates/freeze-plan.md`，**落盘在被构建仓库的 `docs/freeze-plan.md`**——工人只读「仓库内文件 + 交接目录」，放进记录目录里工人就读不到边界。

两条最容易被省、也最省不得的：

- **非目标**——比目标更能防范围漂移。
- **本机无法验证清单**——**冻结时就写**，不要收尾才发现。否则用户会把"检查全绿"读成"能用"。（一次真实运行里我最后才补上，补得越晚越像辩解。）

形态（已授权 ⇒ 通报 / 未授权或不可逆或代价超预期 ⇒ 停下等）见 `SKILL.md`「闸门」。**沉默不是同意。**

## 闸门 B · 变更（必须问用户，带代价核算）

范围或架构一旦变更，产出三样：① 一条 ADR（取代旧的）② **作废清单**（哪些既有决策 / 文件 / 计划失效）③ **代价核算**（作废了多少已完成工作、已花多少轮次）。

**不核算代价的变更 = 让用户闭着眼付账。** 一次真实运行里范围缩过一次，作废了 1 份契约文档、2 个 crate、1 个新 crate 的计划；我当时只记了"作废了什么"、**没有量化**，这是缺陷。

## 闸门 C · 切片完成（默认不问用户）

产出 = 验收记录（`templates/acceptance.md`），**只能由命令输出填充**。

每片都问会让人厌烦，反而促使你跳过闸门 A。只有两种情况例外：该片触及**不可逆操作**（删数据、改 schema、发布、改权限），或改变**用户可见契约**（命令行参数、配置文件格式、对外接口）。

## 闸门 D · 最终验收（必须问用户）

① 全量门禁的真实输出（**最后一次复跑**，不是中间某次的）② **未验证清单逐条交付**，每条写清"为什么没验"与"怎么才能验" ③ 完成定义自检。

**完成定义**（三项齐全才算完，否则要么缩水交付，要么无限打磨）：

- [ ] 每个切片验收通过
- [ ] 缺口表**每一项都有"何时补"**
- [ ] 未验证清单已交付用户

# 规格自检（下发前必做）

**这是本 skill 里最容易省、也最省不得的一步。** 一次真实运行中，我下发的规格里有 **4 处自相矛盾**，全部由工人发现上报——也就是说，**靠的是运气**。那 4 处都落在下面三类里。

> **诚实标注**：本步骤**尚未单独做过对照验证**（四轮测试都没测过它）。价值来自"那 4 处矛盾本可被拦住"这个推论，不是实测。见 `VALIDATION.md`。

| 检查 | 反例（真实发生过的） |
|---|---|
| **可判定吗？** 一条要求若不能用"跑个命令看输出"或"读代码看结构"判真假，它就不是规格，是愿望 | "实现得优雅一点" ✗ |
| **有没有两条互相冲突？** | "掩码必须幂等" + "长度 < 8 时只输出指纹" ⇒ 8 位 hex 输入上冲突，导致合法密钥被明文放行 |
| **签名与散文一致吗？** 函数签名、类型、字段列表，与正文描述必须是同一件事 | 正文写"返回被清除的条数"，签名写 `-> Result<()>`；正文列 8 个字段，契约文档列 7 个 |

**额外必查**：

- **清单类内容只允许一处权威**（字段表、端点表、参数表）——两处清单必然漂移。
- **类型决策要显式**（`Option<T>` 还是 `T`？谁负责归一化时区？），否则工人各处理一遍。
- **规格未覆盖的细节**要写明"按最小做法决定并记录"——否则工人会去猜、或去找别处抄。

# 记录系统

> **判据：这份文档能回答一个在流程里真的会被问的问题吗？** 文档没人读就是负债。

## 目录布局（唯一定义）

```
<repo>/                       被构建仓库 —— 与记录目录**同一个 git 仓库**
  AGENTS.md                   工人合同
  docs/                       仓库内契约 + 冻结方案（`docs/freeze-plan.md`）
  doc/                        记录目录
    00-总纲.md  01-决策记录.md  02-切片计划.md  03-窗口协议.md
    80-已知缺口.md  90-窗口台账.md  99-完成总结.md
    prompts/   下发的指令      handoffs/  交接（**工人唯一可读**）
    流水/      驱动器原始输出 + 裁决记录     验收/  我跑出的证据
```

**三条不变量**（换布局也要满足）：**① 记录目录被版本化**（否则"文档与代码分开提交"无从执行）· **② 工人能读到 `handoffs/`**（否则跨窗口交接断链）· **③ 冻结方案在仓库内**（放记录目录里工人读不到硬约束）。

**⚠ 工人不得读 `doc/` 的其余部分**——总纲 / 决策记录 / 缺口表 / 台账 / 流水 / 验收都是**架构者视角**（未定的决策、对工人表现的记录、我自己的失误），读到会污染它的判断。**只有 `doc/handoffs/` 允许它读。这条靠纪律而非机制执行，必须写进工人合同**（`templates/AGENTS.md §1`）。

## 文档角色（份数按档位定，见 `templates/freeze-plan.md §0`）

| 文档 | 回答的唯一问题 | 不写它会怎样 |
|---|---|---|
| 总纲 | 做什么 / 不做什么 / **范围变过几次** | 范围漂移后没人知道当前边界 |
| 决策记录（ADR） | 为什么这么定 / **否掉了什么** | 已决之事被重新争论；作废决策被继续引用 |
| 切片计划 | 交付单位是什么 / 每片的验收标准 | "做完了"没有判据 |
| 窗口协议 | 怎么派活 / 怎么验收 / 何时换窗口 | 派活质量随机，验收靠感觉 |
| **缺口表** | 哪些没做 / 为什么 / **何时补** | **缺口丢失——最隐蔽的失败** |
| 窗口台账 | 谁做了什么 / 可不可靠 | 无法判断该给多大自由度 |
| 流水 | 原始指令与原始产出 | 只看得到结论，看不到过程 |
| 验收 | **我亲自跑出的证据** | 采信自述 |
| 交接文档 | 跨窗口传递什么 | 换窗口就丢上下文 |
| 完成总结 | 交付了什么 / 凭什么说它是好的 / **哪些没验证** | 读者会把"检查全绿"读成"能用" |

**台账在任何档位都不能省**——它是判断工人可靠性的唯一依据。

**这是下限，不是上限。** 按项目实际情况补充，但每加一份都要过同一个判据：**它回答哪个"在流程里真的会被问"的问题？** 答不上来的不加——**加一份无用文档比少一份更糟**，它会稀释"哪份该读"的判断，让整套文档一起被忽略。

典型需要补充的情形（给的是**判据**，不是一份必加清单）：要维持的**外部契约** → 契约文档；**性能或容量目标** → 基准台账；**实验性探索** → 实验日志；**数据或 schema** → 数据契约；**对外交付或多人协作** → 变更记录 / 发布说明；**合规、安全或许可约束** → 约束清单。

## 每份文档必含的节

| 文档 | 必含 | 关键点 |
|---|---|---|
| 总纲 | 目标 / **范围与变更史（追加不覆盖）** / 非目标 / 运营模型（我是什么、工人是什么）/ 目录约定 | 只留最新版，就答不了"当初为什么改" |
| ADR | 背景 / 决定 / 理由 / **备选与代价** / 影响 | 缺"备选与代价"，决策无法翻案。被推翻时**追加"修订"节，不改原文** |
| 切片计划 | 进度总览（状态列**带验收证据出处**）/ 各片验收标准（可跑的命令 + 期望） | "已验收"没有出处就只是自称 |
| 窗口协议 | 驱动命令 / 指令模板指针 / 上下文预算规则 / 交接模板指针 / 验收协议 / 退回协议 / 台账登记规则 | 它是**流程的可执行定义**；没有它，每个窗口的派活质量靠临场发挥 |
| 流水 | **驱动器原始输出**（`W<n>-<时间戳>.txt`，只引用不得改写）+ **我的裁决记录**（`W<n>-轮<k>.md`） | 加工过的流水失去审计价值。裁决记录里**必须分开"工人出错"与"我写坏规格"** |
| 完成总结 | 交付物 / 规模 / 架构 / 正确性证据 / 真实缺陷 / 方法 / **未完成与未验证（单独成节）** / 如何继续 | "未验证"混进正文，读者就会把"检查全绿"读成"能用" |
| 缺口表 | 待补（`缺口 / 来源 / 影响 / **何时补**`）/ 已消除 / 记录规则 | 空话不入表；每项必须有"何时补" |
| 窗口台账 | 窗口 / 切片 / session / 轮数 / **状态** / 交接 / 退回次数；**工人可靠性记录**；事件记录 | 状态词要有区分度：`已验收` / `中断`（进程消失）/ `超时`（撞上限）/ `已废弃`——混成一个"失败"就丢掉了最有价值的信息 |

**两份通用纪律**：验收类内容只能由命令输出填充（「跑 → 贴」）；代码与文档分开提交。

## 反模式

**叙事式流水账**：写"我们讨论了 X 然后决定 Y"——没人会读第二遍。要的是**结论 + 判据**。
