# 工人载体：子代理、终端会话或命令行调用

委托需要一个能接活的工人。现有三类载体，可单用也可混用；**用哪种由用户确认**（见下文「选择载体」）。契约先写、冻结方案、亲自验收这些纪律与载体无关。

## 三种载体

| | 子代理 | 终端会话 | 命令行调用 |
|---|---|---|---|
| 是什么 | harness 内置的派生代理（Claude Code 的 Agent、OMP 的 `task` 等） | 在后台存活、可用命令行驱动的终端里运行的 agent CLI 或命令（kero 及同类） | 以非交互模式一次性运行 agent CLI（如 `codex exec`、`claude -p`、omp 等同类 CLI 的非交互模式），跑完即退出 |
| 适合 | 起步成本低；结构化产出；通常能取得工具级转录；批量并行 | 交互式 agent CLI 与真实 TTY；在我这一轮结束后继续跑的长进程；用户需要看见或当场介入 | 换 harness 或模型取得独立判断；脚本化批量派工；以退出码、stdout 与输出文件交付，结束判定明确 |
| 短板 | 受 harness 的运行上限约束；续接能力因环境而异 | 通常只有屏缓冲、没有原始转录，读取范围难以事后核对；指令须自包含 | 运行中无法纠正，也不能向用户请求批准；续接依赖该 CLI 的会话恢复能力；权限与沙箱须在启动时一次定好 |

## 选择载体

派工前向用户确认使用哪一种或哪几种载体，与开放问题一起问，结果记入冻结方案 §0。提问时列出本环境实际可用的载体，并按上表给出建议，例如「子代理写代码，`codex exec` 做独立契约复核」。

以下情况不再询问：用户已指定载体；本环境只有一种可用；我是被派来的工人，无人可问（按派工指令执行）。执行中需要增加或更换载体时，按闸门 B 通报；涉及额外费用或新权限时先取得用户决定。

## 派工前核对的能力

按所选载体的实际工具核对下列能力，命令与参数以该工具的文档、`--help` 或对应 skill 为准（如 `kero` skill）。

| 能力 | 用途 | 拿不到时 |
|---|---|---|
| 工人标识 | 续接、取产出、审计的入口，记进台账 | 不派工；没有标识就无法归因 |
| 续接与中途纠正 | 窄任务续轮、同步变更 | 按交接派新工人 |
| 结束判定 | 判断完成、失败与超时 | 以退出码、交接文件与工作区状态为准 |
| 原始转录 | 核对读取范围 | 按 `references/gates.md`「记录系统」标为审计缺口 |
| 工作区隔离 | 并行实现 | **优先用载体原生的 worktree 隔离**（部分 harness 的子代理提供，参数与语义按该工具文档核实）；没有则 `git worktree` 加独立工作目录；都不行则串行。规则见下文「worktree 隔离」 |
| 运行上限 | 预算 | 按冻结方案 §8 自设轮次与时限 |

## worktree 隔离

载体支持原生 worktree 时用它，不手工模拟；每个并行实现工人一个 worktree 和一个独立分支，主工作区只做整合与验收。

- **建 worktree 前先提交硬约束**：契约、冻结方案、`AGENTS.md` 与当轮交接须已在该 worktree 的基线里；未提交的文件不会出现，工人读不到就只能猜。做不到就给绝对路径。
- **工人只在自己的 worktree 分支提交**，各 worktree 的暂存区互不共享；合并、冲突裁决与目标验收由我负责（见 `references/delegation.md`「整合工人产物」）。
- **收尾核对后清理**：每个 worktree 的 `git status` 确认没有未提交改动，产物按来源分支与提交登记进台账后再删除；载体不支持原生 worktree 时退回手工 `git worktree` 或串行。

## 用终端会话或命令行调用时

- 切片指令写进 `orch-doc/prompts/<工人 id>-r<k>.md`，只传一句「读取 `<绝对路径>` 并按其执行」；不把整份契约塞进一次输入。
- 结束判定用退出码、交接文件与 `git status`；终端会话不依赖面板的忙闲标志。
- 要求工人把真实命令输出写进交接文档；终端会话的屏缓冲会被 TUI 重绘覆盖，命令行调用的 stdout 由我落盘保存。
- 命令行调用：启动时显式设定工作目录、权限或沙箱模式与模型；记下 CLI 返回的会话 id 作为工人标识。该 CLI 在本地保存会话记录时，把它当作原始转录。
- 收尾关闭会话、确认进程已退出，并核对没有遗留。
- 本机进程不占子代理请求预算，但占时间、机器资源与该 CLI 的额度，同样受冻结方案 §8 的上限约束；卡住的会话或进程显式终止并判为失败。
