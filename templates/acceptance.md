## 2. 提交核对

> **覆盖本窗口的【全部】提交，不是只有 HEAD**——一个窗口常产出多次提交，一片又可能跨多个窗口。
> 只查 HEAD 会漏掉早前提交里的夹带。

```
$ git log --oneline <本窗口开窗前的基线>..HEAD
$ git diff --stat <基线>..HEAD
<真实输出>
```

- [ ] 提交存在
- [ ] **本窗口的全部提交**都没有夹带本轮之外的文件
- [ ] 没有批量暂存的痕迹
