## 2. Git 状态核对

> **共享分支上的 `基线..HEAD` 不等同于这个工人的产物**——里面混着别的窗口的提交。
> **开窗前的基线状态**（SHA + `git status` + 已有差异）取自台账——不记就无法归因。
> 要查**三样**，并与工人交接里列的 SHA / 路径**逐条核对**。

```
$ git log --oneline <基线>..HEAD        # 提交
$ git diff --cached                     # 已暂存
$ git diff                              # 未暂存
<真实输出>
```

- [ ] 提交存在
- [ ] **本窗口的全部提交**都没有夹带本轮之外的文件
- [ ] **暂存区与工作区没有遗留**未申报的改动
- [ ] 与工人交接里列的 SHA / 路径**对得上**
- [ ] 没有批量暂存的痕迹
