## 2. Git 状态核对

> **定义与理由见 `references/verification.md` 第 2 步**；**派工前的基线状态**（SHA + `git status` + 已有差异）取自台账。

```
$ git log --oneline <基线>..HEAD        # 提交
$ git diff --cached                     # 已暂存
$ git diff                              # 未暂存
$ git status --short --untracked-files=all # 含未跟踪文件
<真实输出>
```

- [ ] 应提交的改动有提交；由主代理待提交的改动已登记
- [ ] **本工人的全部提交**都没有夹带本轮之外的文件

- [ ] 工人的工具调用转录显示提交前按显式路径暂存
